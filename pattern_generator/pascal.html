One Pascal definition

The triangle is read row by row into one sequence of 16-bit numbers: C(0,0), C(1,0), C(1,1), C(2,0)… each mod 216. Every target below reads this same sequence, only from a different position.

Targets (offset into the sequence)

Unchecked targets use the plain default: straight threading, straight treadling, 2/2 twill tie-up. The tie-up is one number from the sequence as a 4×4 bit grid. Each transform is picked by a number from the sequence (value mod 7).
