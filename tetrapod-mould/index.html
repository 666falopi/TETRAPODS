What this study proves

These are candidate sectors cut from a sampled shell around the original default cloud. Shell depth is approximate: the cloud field is not an exact distance field. No flanges, bolts, vents or calibrated print clearances yet.

Collision screening uses 52³ field samples, interior shell probes and 80 translation steps. A hit demonstrates a detected obstruction. “No sampled hit” does not certify full-volume clearance, physical release or printability. Negative draft is measured separately on the cloud surface.

The cloud has not been automatically reshaped for release. This first assignment exposes where its lobes conflict with the four-sector plan.

About this study
THE CONSTRUCTION

Between the branches.

Each sector faces away from one branch and surrounds portions of the other three. Six editable planes divide the shell; they start at the shared origin. Colours and numbers stay attached to the same pieces as they move.

THE NEXT STEP

Design for the exit.
