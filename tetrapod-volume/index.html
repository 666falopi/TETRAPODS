A NOTE ON THE SHAPE

This is a defined generic tetrapod, not an engineering standard or a manufacturer’s mould. Four identical tapered circular arms extend from one center in tetrahedral directions (109.47° apart), with one arm pointing up.

Assumptions & calculation +

Each arm is a flat-ended circular frustum: axial length 1, adjustable root and tip radii (defaults 0.38 and 0.18) in model units. The arms overlap at the center. The whole union is scaled uniformly to your chosen total vertical height; rotating the view does not change that height.

Volume is evaluated on the outer boundary of the union. For each direction from the center, the furthest analytic frustum exit defines the surface. A closed triangulated sphere samples this surface; signed tetrahedron volumes measure the enclosed solid. Overlap is counted once.

Convergence checked at 64, 128, 256 and 512 latitude divisions. The last refinement changes volume by 0.025%. This is an approximation, not a guaranteed error bound. The displayed model uses a lighter mesh.

Uniform scaling: V(h) = V(10) × (h / 10)³ cm³ for the selected radii. Dimensions are the exact bounding extents of the assumed frustums. With the default radii, the 10 cm reference is approximately 235.6 cm³ (0.2356 L). This estimates solid material volume; it excludes casting waste, shrinkage and voids.
